# Exercise 9: Jenkins Multi-Stage Pipeline

## Objective
Automate the build, test, and deployment stages of a Python application using Jenkins.

## Technologies Used
- Jenkins
- Python
- Flask
- Git
- Jenkins Pipeline

## Application
Created a Flask application that returns the message `Hello, Jenkins Multi-Stage Pipeline!`.

## Pipeline Stages
1. **Build:** Checked the Python version, created a virtual environment, and installed dependencies.
2. **Test:** Executed unit tests to verify the application response.
3. **Deploy:** Executed the deployment-stage placeholder.

## Verification
- Flask dependencies installed successfully.
- Unit tests passed.
- All three pipeline stages completed successfully.
- Jenkins reported `Finished: SUCCESS`.

## Conclusion
This exercise demonstrated how Jenkins pipelines automate the build and testing of a Python application through multiple stages.

## Note
The Deploy stage is a placeholder and does not deploy the application to a production environment.
