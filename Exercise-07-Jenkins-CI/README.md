# Exercise 7: Jenkins CI Job

## Objective
To create and execute a Jenkins job for Continuous Integration (CI).

## Tools Used
- Jenkins
- Docker
- Visual Studio Code

## Procedure
1. Started Jenkins using Docker.
2. Opened Jenkins at `http://localhost:8080`.
3. Created a Jenkins Freestyle job named `Exercise-07-CI-Job`.
4. Added build steps to display messages and check the build process.
5. Executed the Jenkins job.

## Result
The Jenkins job executed successfully. The console output displayed `Finished: SUCCESS`.

## Conclusion
This exercise demonstrates how Jenkins automates a basic CI build process.
