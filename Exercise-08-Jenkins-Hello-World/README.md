# Exercise 8: Jenkins Hello World Job

## Objective
To create and execute a simple Hello World job using Jenkins.

## Tools Used
- Jenkins
- Docker
- Visual Studio Code

## Procedure
1. Open Jenkins at `http://localhost:8080`.
2. Create a new Jenkins job named `Exercise-08-Hello-World`.
3. Configure a build step to print a Hello World message.
4. Save the job and click Build Now.
5. Check the Console Output to verify the result.

## Expected Output
`Hello World from Jenkins!`

## Result
The Jenkins Hello World job should execute successfully.

## Conclusion
This exercise demonstrates a basic Jenkins job and build execution.
